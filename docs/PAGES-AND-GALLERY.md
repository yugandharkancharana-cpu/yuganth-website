# Single page with product photo galleries

The approved single-page homepage is restored. The Pantry, Our Roots, What's Next and Contact navigation scroll to sections; Reviews retains its previous hash view. No separate-page browsing is required. Old separate-page URLs redirect to the matching homepage section.

The photo gallery remains inside Explore pack only. In Admin, expand a product, upload up to eight extra photos under Extra photos, add descriptions, arrange them, and Save product. The existing main cover stays first and remains the only image used for cards and the hero. Explore pack shows arrows and thumbnails only when extra photos exist. Actual back-of-pack artwork must be uploaded; none is fabricated.

Installing on an older database requires the additive gallery migration. Export the store database before running the staging installer. Existing private config, stock, prices, users and orders are retained.
